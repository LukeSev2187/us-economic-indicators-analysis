# U.S. Economic Indicators Analysis
An Excel based analysis of U.S. inflation, unemployment, and federal funds rates (2016-2026) featuring FRED data, statistical analysis, correlation and lag analysis, and interactive dashboards to explore economic trends and monetary policy.
## Project Overview
The objective of this project is to investigate the relationships between inflation, unemployment, and the federal funds rate in the United States, with particular attention to how these relationships evolved between 2016-2026.
## Data Sources
Data was collected from the Federal Reserve Economic Data (FRED) database:
* CPIAUCSL: Consumer Price Index for All Urban Consumers Seasonally Adjusted
* UNRATE: Unemployment Rate
* FEDFUNDS: Effective Federal Funds Rate

This analysis uses monthly observations, with September 2026 as the most recent common observation among the three indicators.
## Methods & Tools
**Primary Tool:** Microsoft Excel
Analytical Techniques include:
* Data cleaning and organization
* Year-over-year inflation calculations
* Descriptive statistics
* Correlation analysis
* Interest-rate lag analysis
* Economic period comparisons
* PiviotTables, PivotCharts, and dashboard developmet

## Project Components
### Data Preparation
* **Raw Data:** Original monthly economic data collected from FRED.
* **Clean Data:** Organized and standardized data set prepared for analysis.
* **Calculations:** Derived metrics including year-over-year inflation for use in more complex analysis.

### Statistical Analysis
* **Statistical Analysis:** Descriptive statistics, correlation, and comparisons across economic periods.

### Data Visualization
* **U.S. Economic Indicators Analysis Dashboard:** Overview of major economic indicators and trends.
